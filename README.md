# Tower Console

Compagnon personnel pour *The Tower – Idle Tower Defense*, utilisable sur téléphone et ordinateur.

- Lit la sauvegarde du jeu (`tool_export.json` ou `playerInfo.dat`) depuis Google Drive ou un fichier choisi à la main.
- Historique des runs, plan d'amélioration économie, détail du compte, calculateurs.
- Les données restent dans le Google Drive de l'utilisateur (dossier caché de l'application).

Cette application n'est pas liée à Tech Tree Games.
